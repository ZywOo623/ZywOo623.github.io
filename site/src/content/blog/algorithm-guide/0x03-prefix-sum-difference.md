学习《算法竞赛进阶指南》的 0x03 时，我发现前缀和与差分都在重新表达同一个数组：前缀和记“到这里为止共有多少”，差分记“从这里开始发生了什么变化”。这篇文章记录我学到的公式，以及练习中真实出现的卡点。例子与代码写法是重新整理的，并非教材原文。

## 前缀和：先算好过去，再回答一段区间

对从 1 开始编号的数组 `A`，令 `S[0]=0`，`S[i]=A[1]+...+A[i]`。于是 `S[i]=S[i-1]+A[i]`。要知道 `[l,r]` 的和，就从 `S[r]` 中去掉 `[1,l-1]`：

$$\operatorname{sum}(l,r)=S[r]-S[l-1].$$

我在练习时把 `A=[4,1,5]` 的 `S[3]` 算成了 8。正确的三个前缀依次是 4、5、10，因此 `[2,3]` 的和是 `10-4=6`。公式写对不代表计算一定对；用很短的数组核对一遍很有帮助。

到了二维，`S[i][j]` 表示从 `(1,1)` 到 `(i,j)` 的矩形和。上方与左方的矩形相加，会把左上角的重叠区域算两遍，因此有：

$$S[i][j]=S[i-1][j]+S[i][j-1]-S[i-1][j-1]+A[i][j].$$

任意子矩形也沿用“取大块、减两边、补回重叠”的做法。教材用“激光炸弹”说明它的用途：把目标的价值放进网格，枚举正方形时，用四个前缀和迅速算出覆盖的价值。题目还规定边界上的目标不算被击中，所以建模时需要让目标位于格子中心，使计算的格子范围符合边界规则。

## 差分：只标记变化开始和结束的地方

一维差分定义为 `B[1]=A[1]`、`B[i]=A[i]-A[i-1]`。沿着 `B` 从左往右累加，又能得到原数组。它与前缀和互为逆运算。

把 `A[l..r]` 全部加上 `d` 时，区间内部相邻项一起增加，彼此的差不变。只需留下两个标记：

```cpp
B[l] += d;       // 从 l 开始生效
B[r + 1] -= d;   // 从 r+1 开始取消
```

我曾把“给原数组第 2、3 位加 2”误写成“给差分第 2、3 位都加 2”。用 `A=[2,5,5,1]` 直接检查就能看出问题：更新后是 `[2,7,7,1]`，差分由 `[2,3,0,-4]` 变成 `[2,5,0,-6]`。真正变化的是差分第 2 位和第 4 位，且一加一减。

## 两道例题把“边界”讲具体了

在 *IncDec Sequence* 中，每次给一个区间加 1 或减 1，要让所有数相等。换成差分语言，就是清零 `B[2..n]`。设其中正数之和为 `p`，负数绝对值之和为 `q`。一次区间操作能同时抵消一个正量和一个负量，配对之后剩余的量只能逐个处理，所以最少操作数为 `max(p,q)`；在最少操作次数下，可能的最终常数数组有 `|p-q|+1` 种。

这一题我直接说过“没看懂”。后来用 `A=[1,3,2]` 动手看：将第二个数减 1，数组变成 `[1,2,2]`；因为 `B[2]=A[2]-A[1]`，它减 1，而 `B[3]=A[3]-A[2]`，它加 1。这一步同时削减了一个正差值和一个负差值。再做一次操作，既能得到 `[1,1,1]`，也能得到 `[2,2,2]`，与公式给出的 2 次、2 种对应。

在 *Tallest Cow* 中，一对能相互看见的牛位于 `a`、`b`，需要降低的是**中间**的 `[a+1,b-1]`。如果所有牛先以已知最高身高 `h` 为基准，便可对差分数组写下：

```cpp
d[a + 1]--;  // 第一头中间的牛开始降低
d[b]++;      // 到右端点 b 停止降低
```

最后求 `d` 的前缀和并加上 `h`，就是各头牛的最大可能身高；重复的牛对必须跳过。我在学习时指出过，只展示这两行而不展示完整程序，无法看清读入、去重、还原与输出怎样接起来。于是我用完整程序和位置表核对这个边界：例如牛对 `(2,5)` 让第 3、4 头降低，第 5 头不降低。

## 课外练习：两层差分解决 CF295A

[CF295A Greg and Array](https://codeforces.com/problemset/problem/295/A) 让我遇到了一次很具体的“下标空间混淆”：问题 `[x,y]` 选中的是**操作编号**，操作 `[l,r,d]` 修改的才是**原数组位置**。我先对问题的范围做差分，得到每个操作的执行次数 `sum[i]`；操作 `i` 对覆盖位置的总增量便是 `sum[i] * d[i]`。

为了先验证题意，我用双重循环把每个操作覆盖的位置逐个加上这个增量。这个版本逻辑正确，但大数据 TLE。经讲解后，我才把内层循环换成第二次差分：在 `l[i]` 加上总增量，在 `r[i]+1` 减掉它，最后统一求前缀和还原数组。修改后我反馈最终提交 AC；优化过程有讲解帮助，并非独立首解。这道 Codeforces 题是课外练习，不是教材内容。

## 留给自己的一张检查卡

1. 求区间和：前缀和是否留了 `S[0]=0`？左边是否减 `S[l-1]`？
2. 求二维矩形和：重叠区域是否减一次，并在取子矩形时补回来？
3. 做区间加法：原数组被改的是 `[l,r]`，差分标记是否落在 `l` 和 `r+1`？两个符号是否相反？
4. 使用差分前，是否可以等全部修改结束后再统一求值？
