位运算直接处理整数的二进制位。它适合表示状态、判断某一位是否为 `1`，也常用于优化枚举和集合操作。开始写代码前，先分清 **有符号整数** 与 **无符号整数**：在 C++ 中做掩码和移位时，优先使用无符号类型，能减少符号位带来的意外。

## 二进制与补码

十进制数 $13$ 的二进制是 $1101_2$：

$$13 = (1101)_2 = 8 + 4 + 1$$

计算机通常用补码表示有符号整数。一个常见关系是“按位取反再加一”，即 $-x = \sim x + 1$。不过，处理边界值时不能忽略 C++ 的整数溢出规则；下面的代码使用 `unsigned` 来展示位技巧。

## 常见操作

| 表达式 | 含义 | 例子 |
| --- | --- | --- |
| `x & y` | 两位都为 1 才为 1 | `1101 & 1010 = 1000` |
| `x \| y` | 任一位为 1 就为 1 | `1101 \| 1010 = 1111` |
| `x ^ y` | 两位不同才为 1 | `1101 ^ 1010 = 0111` |
| `x >> k` | 右移 `k` 位 | `13 >> 2 = 3` |
| `x << k` | 左移 `k` 位 | `3 << 2 = 12` |

> 对 `unsigned` 而言，左移前仍要确认移位位数小于类型宽度。竞赛代码中不要默认 `1 << k` 总是安全；需要更宽的掩码时可用 `1ULL << k`。

## 取最低位的 1

`lowbit(x)` 返回二进制表示中最低位的 `1` 所对应的值。例如 `12 = 1100₂`，所以 `lowbit(12) = 4`。

```cpp
#include <bits/stdc++.h>
using namespace std;

unsigned lowbit(unsigned x) {
    return x & (~x + 1u);
}

int main() {
    unsigned x = 12;
    cout << lowbit(x) << '\n'; // 4
}
```

这个技巧会出现在树状数组中。若想数出一个非负整数有多少个 `1`，也可以重复执行 `x &= x - 1`，每次删除最低位的 `1`。

## 小结

- 先写出小数字的二进制形式，再观察运算结果。
- 位掩码优先使用无符号整数，并确认移位范围。
- `x & (x - 1)` 会清除最低位的 `1`；`lowbit(x)` 会保留它。
