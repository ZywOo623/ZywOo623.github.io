# ZywOo623

Personal algorithm site and public notebook: [zywoo623.github.io](https://zywoo623.github.io/).

The editable Astro project lives in [`site/`](site/README.md). Its Markdown articles are in `site/src/content/blog/`. The root HTML, CSS, and JavaScript files are built output for GitHub Pages and legacy links. Edit the source under `site/`, then run its build and export commands to refresh the root copy. GitHub Actions also builds and deploys the source on pushes to `main` and refreshes the public Codeforces snapshot daily.
